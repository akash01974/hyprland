# Spicetify

This directory contains the Spicetify settings, themes, and extension from
`~/.config/spicetify`. The Marketplace custom app is omitted because it is a
bundled third-party application and can be installed through Spicetify.

Before using `config-xpui.ini`, replace `/home/your-user` in `prefs_path` with
the local account's home directory.
