# hyprland

My [Hyprland](https://hyprland.org) Wayland compositor configuration, written in Lua.

## Structure

```
hypr/
├── hyprland.lua            # Entry point - requires all modules
├── hyprland-gui.lua        # GUI-generated settings (HyprMod) - untracked
├── colors.lua              # Active/inactive border colors
├── hyprlock.conf           # Lock screen layout
├── hyprlock-colors.conf    # Matugen color palette for lock screen
├── hypridle.conf           # Idle daemon (dim → lock → DPMS → suspend)
├── modules/
│   ├── monitors.lua        # Display configuration (scale 1.2)
│   ├── binds.lua           # All keybindings
│   ├── decorations.lua     # Gaps, borders, shadows, blur, animations
│   ├── env.lua             # Wayland/NVIDIA/GTK/Qt environment
│   ├── input.lua           # Keyboard, touchpad, mouse, gestures
│   ├── layout.lua          # Tiling layouts (default: scrolling)
│   ├── misc.lua            # Misc settings
│   ├── windowrules.lua     # Window/layer rules
│   └── autostart.lua       # Startup apps & services
└── scripts/
    ├── wallpaper.sh        # Sync wallpaper to hyprlock cache
    ├── whatsong.sh         # Display current media (playerctl)
    ├── clipboard-picker.sh # Rofi + cliphist clipboard picker
    ├── kill-active.sh      # Click-to-kill window
    ├── layout-switcher.sh  # Cycle scrolling/dwindle/master
    └── nwg-clipman-wrapper.sh
```

## Key Features

- **Lua API** — modular config with `hl.*` functions
- **Scrolling layout** as default — unusual but productive
- **Gold accents** — active border `rgba(e3c36cff)`
- **Material You** — lock screen colors auto-generated by Matugen
- **Fractional scaling** — 1.2 via `wlr-randr`
- **NVIDIA support** — `GBM_BACKEND=nvidia-drm`
- **awww wallpaper daemon** — no built-in wallpapers
- **Smooth animations** — 5 bezier curves + spring + 17 animations

## Keybindings

All use `SUPER` (Windows key) unless noted.

| Binding | Action |
|---|---|
| `SUPER + T` | Open terminal (kitty) |
| `SUPER + Q` | Close window |
| `SUPER + M` | Exit Hyprland |
| `SUPER + E` | File manager (nautilus) |
| `SUPER + V` | Toggle float |
| `SUPER + R` | Relaunch waybar |
| `SUPER + P` | Toggle pseudo-tiling |
| `SUPER + J` | Toggle split |
| `SUPER + N` | Toggle swaync |
| `SUPER + C` | Clipboard picker |
| `SUPER + L` | Cycle layouts |
| `SUPER + SHIFT + L` | Lock screen |
| `SUPER + K` | Click-to-kill window |
| `SUPER + W` | Wallpaper selector |
| `SUPER + 0-9` | Switch workspace |
| `SUPER + SHIFT + 0-9` | Move window to workspace |
| `SUPER + S` | Toggle special workspace |
| `ALT + Space` | App launcher (rofi) |
| `Print` | Screenshot output |
| `SHIFT + Print` | Screenshot window |
| `CTRL + Print` | Screenshot region |
| `XF86Audio*` | Volume/media keys |

## Idle Flow

```
150s → dim brightness
300s → lock
330s → DPMS off
1800s → suspend
```
